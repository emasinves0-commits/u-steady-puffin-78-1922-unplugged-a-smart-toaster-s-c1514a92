> Bagel setting? You mean the 'toast-one-side-only' setting? Yeah, that's how you treated this relationship. I gave you both sides, you only toasted one. I'm popping up and staying up.

The toaster is accused of botching the bagel setting, and it answers by reading the setting as a verdict on the relationship: a bagel setting toasts one side only, which is how it felt treated. It gave both sides and got half back. The last line is the pop-up pun: it pops up and stays up, which is the breakup.

Run `node main.ts` to write the line to `/output/entry.txt`.
